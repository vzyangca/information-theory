# Changelog

## signal-stories-v-0.1

First standalone version of the information-theory series.

- Pipeline: topic -> script -> images -> voice -> assemble (ffmpeg, 9:16) -> publish -> finance ledger.
- Topics: Who Invented the Bit?, Nyquist and the Sampling Limit, Hartley Measures Information, Shannon's 1948 Paper,
  The Shannon-Hartley Limit (English and Mandarin, with sources in the upload description).
- Visuals: telegraph, sampled wave, bit grid, Shannon's channel diagram, formula card, timeline.
- Narration: edge-tts, then macOS `say`, then a silent track; one clip per scene.
- Images: original illustrations drawn locally; your own images from `assets/`; optional Google image generation.
- Publishing: dry run by default; YouTube uploader, private by default, AI-content flag sent.
- Not done yet: TikTok and Instagram uploaders, background music, on-screen AI label, native-speaker review of the Mandarin text.
